# Fonts

Fonts are self-hosted; no runtime request is made to Google Fonts.

| File | Family and role | Source |
| --- | --- | --- |
| `fredoka-600-latin.woff2` | Fredoka SemiBold 600, lowercase wordmark | [Google Fonts](https://fonts.google.com/specimen/Fredoka) |
| `inter-latin.woff2` | Inter variable 400–800, product interface | [Google Fonts](https://fonts.google.com/specimen/Inter) |

These unmodified Latin web subsets were downloaded from Google Fonts on
September 30, 2026. Characters outside their coverage use the system fallback.
Both are distributed under SIL Open Font License 1.1. Keep `Fredoka-OFL.txt`
and `Inter-OFL.txt` with the font files, including in distributed containers.
